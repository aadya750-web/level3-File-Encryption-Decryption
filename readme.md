# Basic File Encryption and Decryption using Python

## Project Description

This project is a File Encryption and Decryption application developed using Python. The application uses the Caesar Cipher algorithm to encrypt and decrypt text files.

Users can provide a text file, encrypt its contents, save the encrypted data into a new file, and later decrypt it back to its original form.

## Features

- Encrypt text files
- Decrypt encrypted files
- File handling operations
- Caesar Cipher implementation
- Error handling for missing files

## Technologies Used

- Python
- File Handling
- Caesar Cipher Algorithm
